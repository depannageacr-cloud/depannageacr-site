# Depannage Oost-Vlaanderen — lokale pechhulp door ACR

101 publieke pagina’s; alle 55 huidige Oost-Vlaamse gemeenten en hun deelgemeenten via het officiële Vlaamse gemeenteoverzicht. Gemeentefusies zijn verwerkt; oude routes verwijzen door.

Eigen opbouw als lokale pechhulpwijzer, met regiovinder, pechsituaties, vaste belknop en WhatsApp-locatie delen met toestemming. De bezoeker verstuurt het WhatsApp-bericht zelf. De website registreert geen locatie. De PHP-offerteafhandeling blijft behouden.

Publicatie: GitHub naar bestaande OVH-hosting. Website: https://depannageoostvlaanderen.be/.
